# EDU APP English

Ứng dụng học tiếng Anh, tách từ repo [edu-app-nihongo](https://github.com/letiendungdn/edu-app-nihongo).

| Thư mục | Nội dung |
|---------|----------|
| `apps/english-web` | Next.js frontend |
| `services/english-service` | Module API tiếng Anh |
| `services/english-api` | Ghi chú BFF |
| `packages/prisma-english` | Schema Postgres |
| `packages/nest-prisma-english` | Prisma client cho NestJS |
